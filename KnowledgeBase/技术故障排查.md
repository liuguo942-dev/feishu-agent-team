# 技术故障排查指南

## 页面无法加载

### 排查步骤
1. 检查网络连接是否正常（访问其他网站确认）
2. 清除浏览器缓存：设置 → 隐私与安全 → 清除浏览数据
3. 尝试使用无痕模式打开
4. 更换浏览器（推荐 Chrome 最新版）
5. 如果以上都无效，可能是服务端问题，联系运维

## 接口报错

### 常见错误码
- 400 Bad Request：请求参数有误，检查输入格式
- 401 Unauthorized：未登录或 Token 过期，重新登录
- 403 Forbidden：无权限访问，联系管理员
- 404 Not Found：接口路径错误或资源不存在
- 500 Internal Server Error：服务端异常，联系运维
- 502 Bad Gateway：网关超时，等待后重试
- 503 Service Unavailable：服务过载，稍后重试

## 文件上传失败

### 常见原因
1. 文件超过大小限制（单文件最大 50MB）
2. 文件格式不支持（支持：jpg/png/pdf/docx/xlsx）
3. 网络不稳定导致上传中断
4. 存储空间不足

### 解决方案
- 压缩文件后重试
- 转换格式为支持的格式
- 切换网络环境
- 分批次上传

## 登录异常

### Token 过期
登录态默认 24 小时有效，过期需重新登录。
如频繁提示登录过期，检查系统时间是否准确。

### 异地登录提示
系统检测到异地登录会触发安全提醒。
如非本人操作，建议立即修改密码并开启二次验证。
