# TOOLS.md - 本地配置

## 知识库访问

你有 `bash` 工具可用。
- 路径：`C:\Users\Administrator\KnowledgeBase\`
- 浏览目录：用 `bash` 执行 `ls "C:\Users\Administrator\KnowledgeBase\"`
- 读取文件：用 `bash` 执行 `type "C:\Users\Administrator\KnowledgeBase\文件名.md"`
- **不要用 `read` 工具**，它无法读取 KnowledgeBase 路径下的文件
